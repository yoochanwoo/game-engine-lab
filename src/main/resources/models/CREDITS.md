# 모델 출처

이 폴더의 3D 파일은 데모 씬에 올려 둔 작은 예시입니다. 게임을 배포할 때도 아래 라이선스를 지키면 됩니다.

## Kenney — CC0 1.0

아래 파일은 [Kenney](https://kenney.nl)가 CC0 1.0(퍼블릭 도메인)으로 공개한 것입니다. 출처를 밝히지 않아도 되고, 상업적 이용과 수정도 됩니다. 표기는 의무가 아니지만, 밝힌다면 "Kenney (kenney.nl)"이면 충분합니다.

| 파일 | 원래 팩 |
| --- | --- |
| `tree.glb` | Nature Kit (`tree_default.glb`) |
| `rock.glb` | Nature Kit (`rock_largeA.glb`) |
| `bench.glb` | Furniture Kit (`bench.glb`) |
| `character.glb`, `Textures/colormap.png` | Mini Characters (`character-male-a`) |

팩 페이지:

- https://kenney.nl/assets/nature-kit
- https://kenney.nl/assets/furniture-kit
- https://kenney.nl/assets/mini-characters

CC0 전문: https://creativecommons.org/publicdomain/zero/1.0/

## crate.obj, crate.mtl, crate.png

OBJ 로더를 보여 주려고 이 프로젝트에서 직접 만든 1미터 상자입니다. 별도 라이선스 없이 이 저장소와 같이 사용하면 됩니다.
